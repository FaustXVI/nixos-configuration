# Ubiquitous language review

Review this repository's code and documentation.

The review must focus on the terms used. We want an ubiquitous language : the terms used in the documentation is also found in the code for the same usage.

If a glossary is present, then it is the source of truth for the definitions. Raise concerns if some definitions are missing.

Write your report in .agents-tools/language-review.md
If the file already exists, edit it by removing what is fixed and adding what's new.
